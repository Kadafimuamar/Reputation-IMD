# Contracts

Install:

npm init -y
npm install --save-dev hardhat @nomicfoundation/hardhat-toolbox @openzeppelin/contracts

Deploy the three contracts to Sepolia.

Recommended order:
1. REP token
2. IMD token
3. Reputation(REP token address)

Then put the addresses into extension/config.js.

For the MVP, send some test REP from the deployer wallet to the wallet generated by the Chrome extension.
